# File Forge 1.0

File Forge 1.0 is the first stable Windows release.

## Included

- ISO to GOD conversion
- XEX folder to GOD conversion
- GOD to XEX extraction
- Sequential queues that accept additional jobs while running
- Automatic multi-disc grouping
- Remembered input and output locations
- Optional full verification passes for faster HDD conversions
- Configurable cleanup of incomplete failed output
- Responsive Options and About interfaces
- Local processing with no account, downloads, or telemetry

## Install

Download `fileforge-1.0-windows-x64.zip`, verify its SHA-256 checksum, extract
the complete ZIP, and run `FileForge.exe`.

SHA-256:

```text
7881e5a3ba05fb0280d17f7e5be232ac4e5f6cc0618097cf8d350f58503ad9cb  fileforge-1.0-windows-x64.zip
```

The executable is not Authenticode signed, so Windows SmartScreen may show an
unknown-publisher warning on first launch.

## Important

Use File Forge only with content you own or are legally authorized to copy.
Generated GOD packages are unsigned and require an appropriately configured
JTAG/RGH environment. They are not expected to run on an unmodified retail
Xbox 360.
